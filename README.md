# SGUV — Sistema de Gestión Unificada de Ventas

Aplicación web para kioscos, almacenes y fiambrerías.

## Acceso
- Abrir en navegador moderno (Chrome, Safari, Brave)
- Funciona en PC y celular
- Para cámara: requiere HTTPS o localhost

## Módulos funcionales
- Mi Caja (ventas, escaneo, fiambrería, cobros)
- Stock (inventario, altas, ediciones, ajustes)
- Resumen del día (ventas, arqueo, auditoría)
- Licencias y PIN de seguridad
- Backup/restore de datos

## Deploy en GitHub Pages
1. Subir repo a GitHub
2. Settings → Pages → Source: GitHub Actions
3. Listo. La app se actualiza automáticamente.
